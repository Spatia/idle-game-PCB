# Écran TFT ILI9341 (sans touchscreen) — Documentation de référence

## 1. Présentation

Le **ILI9341** est un contrôleur (driver) pour écrans TFT LCD, fabriqué par ILITEK. Ce n'est pas l'écran lui-même mais la puce qui pilote la dalle. On le trouve intégré dans de très nombreux modules d'écran couleur 2.2" à 2.8", très populaires avec Arduino, ESP32 et Raspberry Pi Pico.

**Caractéristiques principales :**

| Caractéristique | Valeur |
|---|---|
| Résolution | 240 x 320 pixels |
| Couleurs | 262 144 couleurs (18 bits) / 65K en mode 16 bits |
| Tension logique | 1,65 V – 3,3 V |
| Tension d'alimentation | 3,3 V (généralement, certains modules acceptent 5V grâce à un régulateur intégré) |
| Interfaces supportées | SPI (3/4 fils), parallèle 8/9/16/18 bits, RGB |
| Mémoire graphique (GRAM) | 172 800 octets |
| Rétroéclairage | LED, piloté séparément (souvent via une broche LED/BL) |

La version « sans touchscreen » ne possède pas le contrôleur tactile résistif (souvent un XPT2046/ADS7843 sur les modules avec touch). Il y a donc **4 broches en moins** par rapport à un module tactile.

## 2. Brochage (mode SPI — le plus courant)

La plupart des modules ILI9341 sans tactile exposent ces broches :

| Broche | Nom | Fonction |
|---|---|---|
| 1 | VCC | Alimentation (3,3V ou 5V selon module) |
| 2 | GND | Masse |
| 3 | CS | Chip Select (sélection de la puce, actif bas) |
| 4 | RESET | Reset matériel (actif bas) |
| 5 | DC / RS | Data/Command (bascule commande ↔ données) |
| 6 | SDI / MOSI | Données SPI vers l'écran |
| 7 | SCK | Horloge SPI |
| 8 | LED / BL | Alimentation du rétroéclairage (souvent reliée directement à VCC ou via une résistance/PWM) |
| 9 | SDO / MISO | Données SPI depuis l'écran (lecture, optionnel) |

> ⚠️ Le nombre et l'ordre exact des broches varient selon le fabricant du module (Adafruit, HiLetgo, WaveShare...). Vérifiez toujours le sérigraphie au dos de votre module.

## 3. Câblage type

### Avec un Arduino Uno/Nano (5V, logique non native 3.3V)

| ILI9341 | Arduino Uno |
|---|---|
| VCC | 5V |
| GND | GND |
| CS | D10 |
| RESET | D9 |
| DC | D8 |
| SDI (MOSI) | D11 |
| SCK | D13 |
| LED | 5V (ou via résistance 100-220Ω) |
| SDO (MISO) | D12 (optionnel) |

### Avec un ESP32 (natif 3.3V, recommandé)

| ILI9341 | ESP32 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| CS | GPIO 5 |
| RESET | GPIO 4 |
| DC | GPIO 2 |
| SDI (MOSI) | GPIO 23 |
| SCK | GPIO 18 |
| LED | 3.3V |
| SDO (MISO) | GPIO 19 (optionnel) |

Ces GPIO sont des exemples courants (utilisés par défaut dans TFT_eSPI) ; vous pouvez les changer tant que vous adaptez la configuration logicielle.

## 4. Bibliothèques logicielles

**Sur Arduino IDE / PlatformIO :**

- **Adafruit_ILI9341** (+ Adafruit_GFX) — la plus simple pour débuter.
  Installation : Gestionnaire de bibliothèques → rechercher "Adafruit ILI9341"
- **TFT_eSPI** (Bodmer) — plus rapide (DMA, SPI optimisé), très utilisée avec ESP32. Nécessite de configurer un fichier `User_Setup.h` avec le brochage exact.
- **LovyanGFX** — alternative moderne, performante, bon support multi-cartes.

**Sur Raspberry Pi / MicroPython :**

- `luma.lcd` ou pilotes SPI génériques en Python
- Pour MicroPython : bibliothèque `ili9341.py` (driver communautaire, ex. rdagger/micropython-ili9341)

## 5. Exemple de code (Arduino, avec Adafruit_ILI9341)

```cpp
#include <Adafruit_GFX.h>
#include <Adafruit_ILI9341.h>

#define TFT_CS   10
#define TFT_DC   9
#define TFT_RST  8   // ou -1 si RESET relié au reset de l'Arduino

Adafruit_ILI9341 tft = Adafruit_ILI9341(TFT_CS, TFT_DC, TFT_RST);

void setup() {
  tft.begin();
  tft.setRotation(1);              // orientation paysage
  tft.fillScreen(ILI9341_BLACK);
  tft.setTextColor(ILI9341_WHITE);
  tft.setTextSize(2);
  tft.setCursor(10, 10);
  tft.println("Hello ILI9341 !");
}

void loop() {
  // rien ici pour un affichage statique
}
```

## 6. Points d'attention courants

- **Écran blanc / rien ne s'affiche** : vérifier en priorité DC et RESET, souvent inversés ou mal câblés.
- **Couleurs inversées ou étranges** : essayer `tft.invertDisplay(true)` ou vérifier le paramètre `TFT_INVERSION_ON/OFF` dans TFT_eSPI.
- **Alimentation 5V sur un module 3.3V natif** : certains modules ont un régulateur intégré tolérant le 5V sur VCC, mais **DC/CS/SCK/MOSI doivent rester en logique 3.3V** — utilisez un diviseur de tension ou un level shifter si vous pilotez depuis un Arduino 5V pur (Uno/Nano/Mega), sinon risque d'endommager la puce à terme.
- **Vitesse SPI** : TFT_eSPI permet de monter à 40-80 MHz sur ESP32, bien plus rapide qu'Adafruit_ILI9341 (souvent limité à ~20-24 MHz par défaut).
